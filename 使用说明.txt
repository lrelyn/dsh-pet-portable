大肥鱼桌宠 / dsh-pet desktop pet
==================================

制作不易，理性赞助，一块两块不嫌少

这是给 DeepSeek Harness 做的桌面宠物：一只蓝发女仆，会在你的 Windows 桌面
上待机、游走、被你点击、被你拖来拖去。一只纯本地动画角色，不联网、不聊天。

---------------------------------------------------------------------------
怎么用
---------------------------------------------------------------------------

1. 把整个"桌宠"文件夹放到任意位置（桌面、U 盘、D 盘都行）。
   **必须整个文件夹一起拷**，只拷 exe 是没用的。

2. 双击 `大肥鱼桌宠.exe`。
   屏幕上会出现一只桌宠，任务栏不显示它的图标（在托盘里）。

   想要桌面快捷方式（带鲸鱼娘图标）：
   右键 `创建桌面快捷方式.ps1` → 用 PowerShell 运行，
   或管理员 PowerShell 里执行：
     Set-ExecutionPolicy -Scope Process Bypass
     & ".\创建桌面快捷方式.ps1"
   之后桌面上会出现一个带图标的「大肥鱼桌宠」快捷方式，双击即启动。

3. 停止它：任务管理器里结束 `electron.exe`；
   或者直接关掉 DSH Harness 后再运行一次（它检测到已有实例就不会重复启动）。

---------------------------------------------------------------------------
它能做什么 / 不能做什么
---------------------------------------------------------------------------

能：
  · 106 个手绘透明动画（待机 / 游走 / 吃各种东西 / 玩魔方 / 过节…）
  · 点击有反应、拖拽有物理效果、扔出去会弹
  · 右键点她身体可以点播任意动作
  · 右键 →「多开数量」可同时开 1~12 只，尺寸和位置自动错开
  · 字号、大小、位置、动作池、物理参数都能配（data\dsh-pet\main-config.jsonc）

不能（重要）：
  · 不会说话、不能聊天
  · 不显示余额、不发通知
  · 不跟着 DeepSeek Harness 的会话状态联动

原因：这些功能需要 DSH 宿主提供模型调用和凭证，而这个版本是**独立运行**的
（不依赖 DSH 打开）。如果你想要这些功能，得把 dsh-pet 装成 DSH 的插件
（`dsh plugin add dsh-pet`），那时它就长在 DSH 界面里，而不是桌面窗口。

---------------------------------------------------------------------------
关于"需要关闭进程隔离"的提示
---------------------------------------------------------------------------

第一次启动时，程序会先尝试用 Chromium 的正常沙箱启动（更安全）。
如果你的机器上沙箱起不来（有些老机器、虚拟显卡、特殊驱动会这样），
程序会**自动检测到窗口没出来，然后改用 --no-sandbox 重试一次**。

也就是说：
  · 沙箱能用的机器 → 正常运行，进程隔离保持开启
  · 沙箱不能用的机器 → 自动降级，**Windows 进程隔离被关闭**

如果降级了，会在 `pet.log` 里写一行说明。你可以在任务管理器里确认。

这是一个已知的取舍：桌宠只播放本地素材、不加载任何网页，
所以关闭隔离的风险很低；但它确实意味着"这个程序没有 Chromium 的进程沙箱保护"。

---------------------------------------------------------------------------
给别人的时候要说明
---------------------------------------------------------------------------

- 需要 **Windows 10/11 64 位**（Windows 7/8 不支持 —— 运行时报
  「无法定位程序输入点 GetSystemTimePreciseAsFileTime」就是系统太旧，
  现代的 Node/Electron 组件不再兼容 Win7，请升级系统或换一台 Win10 机器）
- 整个文件夹约 **800 MB**（解压后）
- 可能需要允许杀毒软件放行（未签名的程序偶尔被拦）
- 解压后双击即可，不需要装 Node、不需要装 Electron、不需要装 DSH

---------------------------------------------------------------------------
文件结构
---------------------------------------------------------------------------

  大肥鱼桌宠.exe      入口（约 90 MB，含全部启动逻辑）
  创建桌面快捷方式.ps1  生成带鲸鱼娘图标的桌面快捷方式（右键→用 PowerShell 运行）
  使用说明.cmd        双击看本说明
  赞助码.jpg          微信收款码（可删）
  launcher.js         启动器源码（想改逻辑时看这里，注释里有说明）
  runtime\            自带的 Node.js
  electron\           自带的 Electron（渲染窗口用）
  app\                桌宠本体 + 106 个动画素材 + 依赖
  data\dsh-pet\       你的配置（宠物只数、大小、位置、动作池、物理参数）
  pet.log             启动日志（降级等异常会记在这里）
