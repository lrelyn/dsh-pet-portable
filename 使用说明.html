大肥鱼桌宠 · 使用说明

dsh-pet desktop pet · 给 DeepSeek Harness 的桌面伙伴

制作不易，理性赞助，一块两块不嫌少

微信扫码 · 用不上直接删掉这个文件，不影响任何功能

怎么用

  1. 把整个「桌宠」文件夹放到任意位置（桌面、U 盘、D 盘都行）。 必须整个文件夹一起拷，只拷 exe 是没用的。
  2. 双击 大肥鱼桌宠.exe。屏幕上会出现一只桌宠， 任务栏不显示它的图标（在系统托盘里）。
  3. 想要桌面快捷方式（带鲸鱼娘图标）：右键 创建桌面快捷方式.ps1 → 用 PowerShell 运行。
  4. 停止它：任务管理器里结束 electron.exe。

它能做什么 / 不能做什么

能

  • 136 个手绘透明动画（待机 / 游走 / 吃各种东西 / 玩魔方 / 过节…）
  • 点击有反应、拖拽有物理效果、扔出去会弹
  • 右键点她身体可以点播任意动作
  • 右键 →「设置」→「多开数量」可同时开 1~12 只，尺寸和位置自动错开
  • 夜深了她会自己犯困睡觉，闲久了会自己找活干
  • 字号、大小、位置、动作池、物理参数都能配

不能（重要）

  • 不会说话、不能聊天
  • 不显示余额、不发通知
  • 不跟着 DeepSeek Harness 的会话状态联动

原因：这些功能需要 DSH 宿主提供模型调用和凭证，而这个版本是 独立运行的（不依赖 DSH 打开）。如果你想要这些功能，得把 dsh-pet 装成 DSH 的插件（dsh plugin add dsh-pet），那时它就长在 DSH 界面里， 而不是桌面窗口。

右键菜单都有什么

碎碎念催她自言自语一句
对话打开聊天窗（需 DSH 宿主）
回到初始位置停下游走，回到配置的角落
投喂喂一根小鱼干，8 秒冷却
设置 ▸多开数量 / 睡眠时长 / 播放间隔 / 进入工作状态 / 开机自启动 / 使用说明
动作 ▸待机 / 转向 / 拖拽 / 点击回应 / 移动 / 各分类动作，点啥播啥

「动作」里点移动类的条目，她会真的走一段（边界检查、随机距离、 起停节奏与自动漫游完全一致）；带文字的动作（比如「是啊，吃什么」）朝右时会自动朝左， 免得字被镜像颠倒。

关于「需要关闭进程隔离」的提示

第一次启动时，程序会先尝试用 Chromium 的正常沙箱启动（更安全）。如果你的机器上沙箱起不来 （有些老机器、虚拟显卡、特殊驱动会这样），程序会自动检测到窗口没出来， 然后改用 --no-sandbox 重试一次。

也就是说：

  • 沙箱能用的机器 → 正常运行，进程隔离保持开启
  • 沙箱不能用的机器 → 自动降级，Windows 进程隔离被关闭
如果降级了，会在 pet.log 里写一行说明。这是一个已知的取舍：桌宠只播放本地素材、 不加载任何网页，所以关闭隔离的风险很低；但它确实意味着「这个程序没有 Chromium 的进程沙箱保护」。

给别人的时候要说明

项目说明
系统要求Windows 10/11 64 位（Win7/8 不支持。运行时报「无法定位程序输入点 GetSystemTimePreciseAsFileTime」就是系统太旧，现代的 Node/Electron 组件不再兼容 Win7）
体积整个文件夹约 800 MB（解压后）
杀毒软件可能需要允许放行（未签名的程序偶尔被拦）
额外依赖无。解压后双击即可，不需要装 Node、Electron、DSH

文件结构

文件 / 目录作用
大肥鱼桌宠.exe入口（约 90 MB，含全部启动逻辑）
创建桌面快捷方式.ps1生成带鲸鱼娘图标的桌面快捷方式
使用说明.html本页面（右键 → 设置 → 使用说明打开）
赞助码.jpg微信收款码（可删）
launcher.js启动器源码（想改逻辑时看这里）
runtime\自带的 Node.js
electron\自带的 Electron（渲染窗口用）
app\桌宠本体 + 136 个动画素材 + 依赖
data\dsh-pet\你的配置（宠物只数、大小、位置、动作池、物理参数）
pet.log启动日志（降级等异常会记在这里）
