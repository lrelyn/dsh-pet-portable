本打包版包含的第三方修改（非原作者所提供）
------------------------------------------

1. 打包为免安装便携版
   自带 Node.js 与 Electron 运行时，整个文件夹拷贝到任意位置解压即可运行，
   不需要额外安装任何东西，也不写入注册表、不改动系统目录。

2. 桌宠右键菜单新增「设置」子菜单
   整合了多开数量、睡眠时长、重载配置、打开网站、查看余额五项，
   避免顶层菜单里出现重复项。

3. 多开功能
   可同时显示 1~12 只宠物，尺寸与位置按阶梯自动错开。

4. 睡眠功能
   长时间无人交互时自动进入睡眠状态，播放"睡觉第一段 → 第二段 → 第三段"
   三段动画后停在睡姿循环；任意交互（点击 / 拖拽 / 右键）立即唤醒。
   睡眠时长可在右键菜单中设置（永不 / 3 / 5 / 10 / 30 分钟），
   设置保存在浏览器本地存储中，多只宠物共享。

5. 碎碎念的本地台词库
   未配置 API key 时，从 115 条本地台词中随机取句（相邻不重复），
   使桌宠在没有任何模型服务的情况下也会定时自言自语。

6. 修复部分机器上 Electron 沙箱无法初始化的问题
   启动时先尝试使用 Chromium 沙箱；若检测到窗口未能出现，则自动改用
   --no-sandbox 重试一次。该降级会记录在 pet.log 中。

7. 碎碎念与对话接入 DeepSeek 官方 API
   未填写 key 时这两个功能安静不工作；填写 key 后由模型现场生成台词。
