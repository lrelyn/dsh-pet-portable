桌宠的碎碎念与对话 —— 如何启用
================================

最简单的安装方法就是把桌宠文件和此说明扔给ai（豆包，deepseek等）

不调用也有自配的碎碎念，有需求的可以配置

这两个功能需要一个大模型 API key（目前支持 DeepSeek 官方 API）。

填写方法（二选一）
--------------------

方法 A：写文件（推荐，最简单）

  在本文件夹下创建文件：

      data\dsh-pet\api-key.txt

  内容只放 key 本身，一行，例如：

      sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

  保存后重启桌宠（任务管理器结束 electron.exe，再双击 大肥鱼桌宠.exe）。


方法 B：设环境变量

  把 DEEPSEEK_API_KEY 设成你的 key，再启动桌宠。


关于费用
--------

  · 碎碎念：一句 20 字以内，每隔一段时间才会说一句，消耗极低
  · 对话：正常对话的消耗，和你直接用 DeepSeek 一样


获取 key
--------

  1. 打开 https://platform.deepseek.com/
  2. 登录后进入 API keys 页面
  3. 创建一个新的 key
  4. 新用户通常有赠送额度


注意
----

  · key 只保存在你自己的电脑上，不要发给别人
  · 删掉 api-key.txt 即可关闭这两个功能，桌宠其它功能不受影响
  · 没有 key 时，碎碎念和对话会安静地不工作，不会弹错误


桌宠的台词库 —— 如何修改
================================

桌宠在"无聊"时会自己冒泡说话（默认每 5 分钟一次）。
这些句子来自一个台词库，你可以随意增删改。

在哪里改
--------

  大肥鱼桌宠\data\dsh-pet\main-config.jsonc

（就是和本说明同一个文件夹里，往下进 data\dsh-pet\，
  找到 main-config.jsonc，用记事本打开）

用记事本打开，找 "idleLines" 这一段，它是一个字符串数组：

    "idleLines": [
      "今天也没做什么呢~",
      "主人在忙吗？我先趴一会儿。",
      "……"
    ]

规则很简单：

  · 每句话用一对英文双引号包住
  · 句子之间用英文逗号分隔，最后一句后面不要加逗号
  · 可以加任意多条，几百条也没问题
  · 加完保存，然后重启桌宠（任务管理器里结束 electron.exe，
    再双击 大肥鱼桌宠.exe）


怎么改得好看
------------

  · 长度控制在 20 字以内，太长了气泡装不下
  · 语气保持一致（现在是温柔+有点俏皮的女仆口吻）
  · 换个角色性格就整体重写，例如换成傲娇、换成冷淡、换成元气
  · 同一句不会被连续说两次（程序自动处理）


现在的规模
----------

  115 句，分 16 种心情：

    发呆 / 日常 / 催你休息 / 好奇 / 想吃东西 / 天气 / 时间 /
    想被摸 / 犯困 / 鼓励 / 吐槽 / 自嘲 / 夜晚 / 等你 /
    碎碎念 / 反应

按每天 5 分钟一次（约 288 次/天）算，这些句子够用一个多月
不重复。嫌少的话照上面的方法继续加。


和"模型碎碎念"的关系
--------------------

  · 没有配置 API key 时：说本地台词库里的句子
  · 配了 key 且调用成功：说模型现场生成的句子（更聪明，但更费 token）
  · 配了 key 但调用失败（key 错/余额不足/超时）：自动回退到本地台词

  所以就算你不配 key，她也会一直有话说；配上 key 只是让内容更随机应变。
