# 二、总体架构：三维状态 + 好感度
在现有单维心情（mood）基础上，扩展为三维短期状态 + 一维长期好感度的完整状态体系：
| 维度 | 范围 | 时间尺度 | 核心驱动 | 类比 |
| 心情 mood | 0~100 | 分钟~小时 | 事件/互动 | 现有，情绪 |
| 精力 energy | 0~100 | 小时~天 | 工作消耗/睡眠恢复 | 拓麻歌子 energy |
| 饱食 hunger | 0~100 | 小时~天 | 时间消耗/喂食恢复 | 拓麻歌子 hunger |
| 好感度 affinity | 0~100 | 天~周 | 长期陪伴累积 | VPet 好感度 |

四维联动关系：
- 饱食 < 30：每分钟心情 -0.5（饿肚子开心不起来），精力恢复速度 ×0.5
- 精力 < 20：每分钟心情 -0.3（太累了），动作播放速度 ×0.7，拒绝主动玩耍
- 心情 > 70：精力恢复 ×1.2（心情好恢复快），喂食效果 ×1.1
- 好感度越高：正收益事件加成越大（最高 ×1.5），解锁更多互动和台词
- 好感度低：互动反应平淡，部分亲密动作拒绝
# 三、精力 / 饱食维度深入方案
## 3.1 精力（energy）设计
精力代表桌宠的疲劳/清醒程度，核心是消耗与恢复的昼夜循环。
| 状态 | 精力范围 | 行为表现 | 动画/台词 |
| 精力充沛 | 80~100 | 动作活泼，主动玩耍，移动快 | 超大伸懒腰、可爱宅舞、元气挥手 |
| 正常 | 40~79 | 标准行为 | 待机呼吸休闲 |
| 疲惫 | 20~39 | 频繁打哈欠，动作变慢，不太想玩 | 哈欠连天、迷糊犯困、睡眼惺忪 |
| 精疲力竭 | 0~19 | 走路摇晃，拒绝互动，可能原地睡着 | 原地小憩沉眠、打瞌睡被惊醒 |

精力消耗与恢复速率：
| 场景 | 消耗/恢复 | 速率（/分钟） | 说明 |
| 工作中（working） | 消耗 | -1.5 | 约 60 分钟从满精力到疲惫 |
| 摸鱼/玩耍 | 消耗 | -0.5 | 玩也会累，但慢 |
| 待机 | 消耗 | -0.2 | 基本不动，消耗很慢 |
| 睡眠中 | 恢复 | +4 | 约 25 分钟从0恢复到满 |
| 夜间待机（22-5点） | 恢复 | +1 | 不睡觉也会缓慢恢复 |
| 吃饱后（hunger>80） | 恢复加成 | ×1.3 | 吃饱了恢复快 |

自动行为：
- 精力 < 15 且当前是夜间（22-5点）：自动进入睡眠，播放睡觉动画
- 精力 < 10 且白天：原地睡着（播放原地小憩沉眠），气泡“太累了……让我睡会儿”
- 睡眠中精力恢复到 90 以上：自然醒来，播放睡眼惺忪→伸懒腰，心情 +3
## 3.2 饱食（hunger）设计
饱食代表饥饿/饱腹程度，核心是随时间饥饿和喂食恢复。
| 状态 | 饱食范围 | 行为表现 | 动画/台词 |
| 吃饱 | 80~100 | 满足，可能犯困 | 吃饱打嗝（新）、悠闲哼歌 |
| 正常 | 40~79 | 标准行为 | 待机呼吸休闲 |
| 饥饿 | 20~39 | 肚子叫，主动要吃的，看食物 | 捂肚子（新）、翻钱包、吃白饭 |
| 饿坏 | 0~19 | 饿趴，心情持续下降，走不动 | 饿趴（新）、垂头叹气 |

饱食消耗与恢复：
| 场景 | 速率 | 说明 |
| 自然消耗（所有时间） | -0.4/分钟 | 约 4 小时从吃饱到饥饿 |
| 工作中 | -0.6/分钟 | 干活饿得快 |
| 睡眠中 | -0.1/分钟 | 睡觉消耗慢 |

食物体系（不同食物恢复不同饱食）：
| 食物 | 恢复饱食 | 对应现有动画 | 好感度 | 冷却 |
| 小鱼干 | +15 | 吃小鱼干 | +2 | 8秒 |
| 零食 | +10 | 大口吃零食 | +1 | 8秒 |
| 白饭 | +25 | 吃白饭 | +1 | 15秒 |
| 盒饭 | +35 | 吃盒饭 | +2 | 20秒 |
| Token | +5（特殊） | 吃Token/偷吃Token | 0 | 5秒 |
| 节日食物 | +30 | 粽子/饺子/月饼/汤圆等 | +3 | 20秒 |
| 奶茶/冰淇淋 | +8（但精力-5） | 喝奶茶/吃冰淇淋 | +2 | 10秒 |

自动行为：
- 饱食 < 25：每 3~5 分钟主动冒泡“肚子好饿……”，并播放捂肚子动画
- 饱食 < 10：饿趴在地上，每分钟心情 -0.5，好感度每小时 -1
- 饱食 > 90：喂食时拒绝，“吃饱啦吃不下了”，播放摆手动画（新）

# 四、好感度系统深入方案
## 4.1 好感度与心情的区别
| 对比项 | 心情 mood | 好感度 affinity |
| 时间尺度 | 短期（分钟~小时） | 长期（天~周） |
| 波动 | 频繁上下波动 | 缓慢累积，几乎不下降 |
| 作用 | 影响当前行为/动画 | 解锁内容/决定关系深度 |
| 重置 | decay 回归 | 不回归，只随长期缺席下降 |
| 上限 | 100，可反复达到 | 100，需长期经营 |

## 4.2 好感度等级与解锁
| 等级 | 范围 | 关系名 | 行为特征 | 解锁内容 |
| Lv.1 | 0~19 | 陌生 | 话少、拘谨、拒绝亲密动作 | 基础待机/点击 |
| Lv.2 | 20~39 | 认识 | 正常互动 | 喂食、碎碎念 |
| Lv.3 | 40~59 | 熟悉 | 每天主动打招呼，有专属问候 | 双击抱抱、跟随模式 |
| Lv.4 | 60~79 | 亲密 | 撒娇、要抱抱、会吃醋 | 撒娇动作、专属台词、摸头进阶 |
| Lv.5 | 80~94 | 羁绊 | 深度依赖，不能容忍被忽视 | 专属称呼、羁绊动作、特殊节日剧情 |
| Lv.6 | 95~100 | 心灵相通 | 全解锁，彩蛋 | 全部动作+隐藏彩蛋 |

# 五、离线演化深入方案
## 5.1 核心机制
桌宠关闭期间状态继续演化。关闭时保存完整快照（时间戳+四维状态），下次启动时计算离线时长，用一次性推演模拟这段时间的变化，并触发对应的回归剧情。
离线推演规则：
| 维度 | 离线期间变化 | 说明 |
| 精力 | 离线前30分钟按睡眠恢复到满，之后保持满 | 假设她自己睡了一觉 |
| 饱食 | 持续按睡眠速率消耗（-0.1/分钟） | 离线越久越饿，上限扣到0 |
| 心情 | 前2小时不变，之后每小时 -1（孤独） | 被独自留下 |
| 好感度 | 1天内不降，3天内-1/天，之后加速 | 见好感度规则 |

## 5.2 回归剧情（按离线时长）
| 离线时长 | 状态结果 | 回归动画 | 台词/剧情 |
| <1小时 | 几乎无变化 | 开心跃动 | 你回来啦～ |
| 1~8小时 | 略饿 | 元气挥手 | 你去哪了呀，等你好久 |
| 8~24小时 | 饥饿，心情略降 | 捂肚子+开心 | 你终于回来了！我好饿 |
| 1~3天 | 饿坏，好感度降 | 委屈巴巴（新） | 你是不是不要我了…… |
| 3~7天 | 饿趴，好感度大降 | 生气扭头（新） | 哼，不理你了（需要哄） |
| >7天 | 触发离家出走彩蛋 | 小纸条（新） | 桌面上留纸条“我走了”，哄回剧情 |

离家出走彩蛋（>7天）：
- 启动后桌宠不在原位，原位贴一张小纸条（“我出去散心了，哼”）
- 玩家点击纸条，桌宠从屏幕边缘慢慢挪回来，需要连续喂食+互动哄回
- 哄回后好感度恢复到 30，不会真的永久消失（避免惩罚过重）
- 这是长线玩家的专属剧情，增加情感投入

# 六、多宠互动深入方案
## 6.1 现有基础
physics.ts 已有多宠物飞行碰撞（一只被甩出撞到另一只按动量守恒弹开），但这只是物理层面，没有社交互动。petCollision 配置默认关闭。
## 6.2 社交互动类型
| 互动 | 触发条件 | 动画表现 | 状态影响 | 概率 |
| 贴贴 | 两只靠近，静止相遇 | 互相蹭一蹭（新） | 双方心情+5、好感+1 | 35% |
| 追逐 | 一只活跃时靠近另一只 | 前面跑后面追（新） | 追方开心，被追方-2 | 15% |
| 一起玩 | 两只都精力高 | 各播玩耍动画（玩水枪/抛接） | 双方心情+8 | 20% |
| 聊天 | 两只靠近待机 | 互相冒泡对话 | 心情+3 | 15% |
| 抢食 | 喂食时其他只在附近 | 扑过来抢（新） | 抢到的+饱食，没抢到-3心情 | 喂食时30% |
| 一起睡 | 夜间两只靠近 | 并排睡觉（新） | 精力恢复×1.2 | 夜间40% |
| 推搡/打架 | 双方心情都差 | 互相推（新） | 双方心情-5 | 心情差时25% |
| 无视 | 其他情况 | 各走各的 | 无 | 剩余 |

## 6.3 宠物间关系值
每两只宠物之间维护独立的关系值（0~100），影响互动倾向：
| 关系 | 范围 | 互动倾向 |
| 好朋友 | 70~100 | 贴贴/一起玩/一起睡概率高，从不打架 |
| 普通 | 30~69 | 标准概率 |
| 冤家 | 0~29 | 打架/追逐概率高，很少贴贴 |

- 每次正面互动关系 +2，每次打架 -5
- 关系值随多开存档持久化
- 玩家可撮合：对两只分别做正面互动，或喂食时让她们一起吃

## 8.2 头顶状态图标（不打断动画）
在不打开面板的情况下，通过桌宠头顶小图标传递关键状态：
| 图标 | 出现条件 | 含义 |
| 饭碗图标 | 饱食 < 30 | 我饿了，喂我 |
| Zzz | 精力 < 20 或想睡 | 好困 |
| 爱心 | 好感度升级/想撒娇 | 喜欢你/要抱抱 |
| 玩具图标 | 精力高且长时间没玩 | 陪我玩 |
| 问号 | 需要确认 | 等你操作 |

- 图标半透明、小巧，不遮挡主动画
- 多个状态同时存在时轮播显示，优先级：饥饿 > 困倦 > 想玩
- 点击图标直接触发对应动作（点饭碗直接打开喂食菜单）
## 8.3 气泡与外观反馈
- 气泡边框颜色随心情变化（开心粉色、疲惫灰色、生气红色）
- 精力低时动画整体播放速度变慢（0.7倍），直观表现疲惫
- 好感度低时气泡字体偏正式，高时偏口语撒娇
- 回归欢迎时屏幕边缘有短暂的小特效（爱心/星星），不喧宾夺主

├── 陪我玩（互动/番茄钟）
├── 状态（打开状态面板）

# 十一、验收标准
- 持续工作约1小时，精力降到疲惫区间，桌宠频繁打哈欠、动作变慢
- 不喂食约4小时，饱食降到饥饿，桌宠主动捂肚子要吃的
- 喂食不同食物恢复不同饱食，吃饱后拒绝再喂
- 精力极低时自动睡觉，睡约25分钟后自然醒来，精力和心情恢复
- 好感度随互动累积升级，每级解锁对应动作（Lv3能抱抱、Lv4会撒娇）
- 关闭后再打开，状态按离线时长演化，播放对应回归剧情
- 离线超过7天触发离家出走纸条彩蛋，可哄回
- 多开两只相遇时触发贴贴/追逐等互动，关系值随互动变化
- 状态面板正确显示四维状态，头顶图标在对应状态出现
- 所有功能可独立开关，关闭后完全等价当前版本
